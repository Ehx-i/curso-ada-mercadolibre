# ☕ Ejercicios de Java - ADA & Mercado Libre

Repositorio destinado al almacenamiento y organización de los ejercicios, desafíos y prácticas desarrollados durante el curso de programación Java impartido por ADA en colaboración con Mercado Libre.

## 📚 Objetivos

- Fortalecer la lógica de programación.
- Aprender los fundamentos de Java.
- Aplicar conceptos de programación orientada a objetos (POO).
- Desarrollar buenas prácticas de codificación.
- Crear soluciones a problemas propuestos durante el curso.

## 🛠️ Tecnologías utilizadas

- Java
- JDK 17+ (o la versión utilizada en el curso)
- IntelliJ IDEA / VS Code
- Git y GitHub

## 🚀 Cómo ejecutar los ejercicios

1. Clonar el repositorio:

```bash
git clone https://github.com/tu-usuario/nombre-del-repositorio.git
```

2. Acceder al proyecto:

```bash
cd nombre-del-repositorio
```

3. Compilar un archivo Java:

```bash
javac NombreArchivo.java
```

4. Ejecutar el programa:

```bash
java NombreArchivo
```
